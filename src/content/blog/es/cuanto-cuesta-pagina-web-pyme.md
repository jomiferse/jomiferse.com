Una página web para una pyme puede costar desde unos **500 euros por una landing sencilla** hasta **varios miles de euros** cuando incluye muchas páginas, reservas, varios idiomas, integraciones o contenido complejo. Una web corporativa pequeña, con un alcance bien definido, suele quedar entre ambos extremos.

No hay una tarifa universal. Tampoco tendría sentido cobrar lo mismo por una página para validar un servicio que por la web de un hotel con habitaciones, idiomas y conexión con un motor de reservas. La cifra solo sirve cuando va acompañada de un alcance.

Los rangos de esta guía están actualizados en agosto de 2026. Son escenarios orientativos para proyectos freelance o equipos pequeños en España, no un presupuesto cerrado ni una media oficial del mercado. Normalmente hay que añadir IVA y separar dominios, alojamiento y licencias cuando no estén incluidos.

## Rangos según el tipo de web

| Tipo de proyecto                     | Rango orientativo | Qué suele incluir                                                                              |
| ------------------------------------ | ----------------: | ---------------------------------------------------------------------------------------------- |
| Landing para un servicio             |     500 a 1.500 € | Una página, estructura, diseño responsive, copy base, formulario, analítica y publicación      |
| Web de negocio pequeña               |   1.200 a 3.000 € | Inicio, servicios, sobre el negocio, contacto, contenido editable y SEO técnico básico         |
| Web con catálogo, reservas o idiomas |   2.500 a 6.000 € | Más contenido, plantillas, integración externa, migración y pruebas de varios recorridos       |
| Web con funcionalidad a medida       |     Desde 6.000 € | Área privada, reglas de negocio, datos propios, pagos o integraciones que necesitan desarrollo |

Una web de negocio con cinco secciones claras puede empezar alrededor de 490 euros si el contenido y el recorrido son sencillos. Un proyecto de [diseño web WordPress](/es/services/diseno-web-wordpress/) suele subir cuando el equipo necesita editar muchas páginas, trabajar con plugins concretos o migrar contenido existente.

El precio de salida no dice por sí solo si una propuesta es cara o barata. Una landing de 700 euros puede estar bien resuelta y una web de 4.000 puede llegar sin textos, medición ni mantenimiento claro. Conviene revisar las partidas.

## Qué cambia el presupuesto

### La cantidad y el estado del contenido

Cinco páginas con textos terminados no requieren el mismo trabajo que cinco ideas repartidas entre documentos, emails y una web antigua. Ordenar la oferta, redactar, seleccionar imágenes y decidir la jerarquía forma parte del proyecto aunque no aparezca en una lista de funciones.

Si el negocio tiene varios servicios, es mejor dar a cada uno una página útil que esconderlos todos en un bloque genérico. Eso añade trabajo, pero también permite responder búsquedas más concretas y enviar a cada cliente a la información que necesita.

### El diseño y la identidad visual

Trabajar con una identidad existente reduce decisiones. Si no hay logotipo, tipografía, paleta ni criterio fotográfico, alguien tendrá que definir una base. No hace falta contratar un rebranding completo para publicar una buena web, pero sí acordar un sistema visual coherente.

Una plantilla puede ahorrar horas cuando encaja con la estructura. Deja de ahorrar cuando hay que forzar cada sección, corregir problemas móviles o desmontar funciones que nunca se usarán.

### Edición, reservas e integraciones

Un formulario que envía un email es sencillo. Un formulario que crea un contacto en el CRM, etiqueta el origen y avisa al comercial tiene más piezas. Lo mismo ocurre con reservas, pagos, catálogos, mapas, newsletters o sincronización con un sistema de gestión.

La pregunta útil no es "¿se puede conectar?", sino qué debe pasar cuando la conexión funciona, falla o recibe datos incompletos. Esas excepciones influyen más en el coste que el logotipo de la herramienta.

### Idiomas y migración

Una web bilingüe no consiste solo en duplicar páginas. Hay que preparar traducciones, rutas, enlaces entre idiomas, metadatos y una forma sensata de mantener ambas versiones. Si además se parte de una web existente, conviene inventariar las URLs y decidir cuáles se conservan, se fusionan o se redirigen.

### Alojamiento, licencias y mantenimiento

El proyecto inicial y el coste anual son cosas distintas. Antes de aceptar una propuesta, pide que separe:

- dominio y alojamiento
- licencias de tema, plugins, tipografías o imágenes
- copias de seguridad y actualizaciones
- soporte para pequeños cambios
- propiedad de las cuentas, código y contenidos
- coste de servicios externos como email, reservas o analítica

Una web barata con cinco licencias anuales que solo controla el proveedor puede salir cara al cambiar de profesional. La entrega debería dejar claro qué posee el negocio y cómo se recuperan los accesos.

## WordPress, Astro o desarrollo a medida

No elegiría la tecnología por moda. La elegiría según quién va a editar, qué funciones necesita la web y cuánto mantenimiento acepta el negocio.

**WordPress** encaja cuando el equipo quiere publicar o modificar páginas con frecuencia, necesita un catálogo manejable o depende de un plugin probado. Hay que cuidar las actualizaciones, las copias y la calidad de las extensiones.

**Astro** funciona bien para webs de servicios, landings y contenido que no cambia a diario. Ofrece una base ligera y mucho control sobre el resultado. La edición puede hacerse en archivos o conectarse a un gestor si de verdad hace falta.

**El desarrollo a medida** tiene sentido cuando la web ya no es solo una web: hay usuarios, datos propios, pagos con reglas particulares, permisos o un flujo que no resuelve una herramienta estándar. Empezar por aquí sin una necesidad clara suele inflar el presupuesto.

## Tres ejemplos de pyme

### Una cafetería de barrio

Necesita que alguien vea el menú, el horario, la ubicación y cómo reservar desde el móvil. Una landing o web pequeña puede ser suficiente. El gasto crece si el menú cambia cada semana, hay pedidos online o eventos que el equipo quiere publicar sin ayuda.

Yo priorizaría carga rápida, fotografías propias, información local coherente y botones que abran el mapa, la llamada o la reserva. No empezaría con un área privada.

### Un alojamiento rural

Aquí aparecen habitaciones, tarifas orientativas, políticas, varios idiomas y un motor de reservas externo. Aunque no se construya el sistema de reservas, hay que integrar bien el recorrido y comprobarlo en móvil.

También merece atención la migración de URLs si la web ya recibe visitas desde buscadores o portales. Este caso suele acercarse más al rango medio que a una landing básica.

### Un despacho o empresa de reformas

El objetivo suele ser filtrar consultas y mostrar trabajos relevantes. Necesita páginas de servicio, zonas atendidas, proyectos bien explicados y un formulario que pida la información justa.

El presupuesto dependerá más del contenido que de una función compleja. Conseguir fotografías, redactar casos y ordenar servicios lleva tiempo. A cambio, esas páginas pueden responder dudas antes de la llamada.

## Qué debería incluir un presupuesto web

Una propuesta útil permite saber qué se entregará y qué falta por aportar. Como mínimo, revisaría estos puntos:

1. páginas o plantillas incluidas
2. responsabilidad sobre textos, traducciones e imágenes
3. número de rondas de revisión
4. comportamiento móvil y criterios de accesibilidad
5. formularios, medición e integraciones
6. migración, redirecciones y conservación de SEO si existe otra web
7. alojamiento, licencias y costes recurrentes
8. pruebas, publicación, accesos y documentación
9. mantenimiento incluido después del lanzamiento
10. exclusiones y precio de cambios fuera del alcance

Si una propuesta no concreta el resultado, esta [guía para evaluar un presupuesto de software](/es/blog/evaluar-presupuesto-software-a-medida/) ayuda a detectar incertidumbre escondida aunque el proyecto sea una web.

## Señales de un presupuesto mal planteado

Desconfiaría de una cifra cerrada ofrecida antes de preguntar por contenido, edición, integraciones o web anterior. También de una lista enorme de funciones que el negocio no ha pedido.

El extremo barato suele omitir copy, pruebas, migración, accesos o soporte. El extremo sobredimensionado añade una plataforma a medida donde bastaba una buena web de servicios. Los dos fallan por el mismo motivo: el alcance no parte de cómo vende y trabaja el negocio.

Antes de contratar, merece la pena revisar [qué debe tener una web profesional para captar clientes](/es/blog/que-debe-tener-web-profesional-para-captar-clientes/). Ayuda a separar las partes útiles de los adornos.

## Cómo pedir una estimación que sirva

No necesitas preparar un documento técnico. Basta con responder:

- qué vende el negocio y a quién
- qué debería hacer una persona después de visitar la web
- qué páginas o contenidos existen ya
- quién actualizará la web
- qué herramientas deben conectarse
- qué fecha importa y por qué
- qué presupuesto máximo tendría sentido para esta fase

Con esa información se puede proponer una primera versión y dejar mejoras posteriores fuera del precio inicial. También permite comparar ofertas sin contar páginas como si todas tuvieran el mismo trabajo.

Si el negocio está en Granada o trabaja con público local, puedes revisar el enfoque de [diseño web en Granada](/es/diseno-web-granada/). Para un caso concreto, una primera conversación debería terminar con un alcance más claro, no con presión para comprar la opción más grande.

## Preguntas frecuentes

### ¿Cuánto tarda una web para una pyme?

Una landing acotada puede estar lista en dos o tres semanas. Una web con varias páginas, contenido pendiente, idiomas o integraciones puede necesitar entre cuatro y ocho semanas. El calendario depende mucho de cuándo llegan textos, accesos y revisiones.

### ¿El mantenimiento es obligatorio?

La web siempre necesita un responsable, aunque el trabajo sea pequeño. En WordPress hay actualizaciones, copias y plugins. En una web estática hay menos mantenimiento de aplicación, pero siguen existiendo dominio, alojamiento, formularios y cambios de contenido.

### ¿Puedo empezar por una sola página?

Sí. Si la oferta es concreta, una landing bien planteada permite validar el mensaje y empezar a recibir consultas. Después puede crecer con páginas de servicio o contenidos basados en preguntas reales.

### ¿El SEO está incluido en el precio?

Conviene distinguir una base técnica correcta de una estrategia SEO continua. Metadatos, estructura, rastreo, rendimiento y sitemap deberían formar parte de una buena entrega. Investigación extensa, contenido recurrente, SEO local y captación de enlaces son trabajos adicionales.

### ¿Qué ocurre si ya tengo una web?

Primero hay que decidir qué merece conservarse. A veces basta con mejorar estructura y mensajes. Otras veces el sistema actual limita cualquier cambio. La guía sobre [rediseñar una web o hacerla de nuevo](/es/blog/redisenar-web-o-hacerla-de-nuevo/) plantea esa decisión paso a paso.
