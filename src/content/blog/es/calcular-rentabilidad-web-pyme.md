Para calcular la **rentabilidad de una web para una pyme**, compara el margen adicional y los ahorros atribuibles a la web con todo lo que cuesta crearla y mantenerla durante el mismo periodo. Contar visitas o dividir la facturación entre el precio del diseño deja fuera demasiadas cosas.

Una web puede ayudar a vender, reducir consultas repetidas o facilitar reservas. Cada efecto se mide de forma distinta. Antes de pedir un presupuesto, conviene escribir qué esperas mejorar y qué dato demostraría esa mejora.

Esta guía usa un ejemplo inventado para explicar el cálculo. Las cantidades no son resultados de clientes, tarifas ni una previsión de ingresos. Puedes sustituirlas por los datos de tu negocio y comprobar si el proyecto sigue teniendo sentido con un escenario prudente.

## Qué significa que una web salga rentable

Imagina una empresa que ofrece mantenimiento de equipos. Su web recibe solicitudes, pero el contrato se cierra por teléfono. El valor económico aparece cuando esa solicitud acaba en un trabajo que deja margen, no cuando alguien pulsa el botón de contacto.

Una tienda tiene otra ruta: visita, pedido, pago y entrega. Una consulta profesional puede tener reservas que después se cancelan. Por eso, la primera decisión es definir el resultado que vas a contar: contratos cobrados, pedidos servidos o citas atendidas.

También necesitas un punto de comparación. Si ya conseguías cinco clientes mensuales con la web antigua y después consigues siete, atribuir los siete al rediseño exageraría el resultado. Hay que investigar los dos adicionales y comprobar si cambiaron también campañas, precios o disponibilidad.

La guía de [cuánto cuesta una página web para una pyme](/es/blog/cuanto-cuesta-pagina-web-pyme/) sirve para estimar la inversión. Aquí vamos a relacionar ese coste con resultados que puedan sostenerse.

## La fórmula del ROI y sus límites

Para un periodo de doce meses, puedes usar este modelo sencillo:

```text
Beneficio atribuible = margen adicional + ahorro monetario comprobado
Coste total = inversión inicial + costes de funcionamiento del periodo
ROI = (beneficio atribuible - coste total) / coste total × 100
```

El margen adicional es lo que queda de las ventas nuevas después de sus costes variables: materiales, transporte, comisiones y trabajo necesario para prestar el servicio, según cómo calcule tu empresa su margen. Mantén el mismo criterio en todos los escenarios.

El coste total incluye desarrollo, contenido, puesta en marcha y funcionamiento. Si necesitas anuncios para conseguir esas ventas, incluye también ese gasto. No puedes atribuir a la web los resultados de una campaña y esconder el coste de conseguir las visitas.

Este modelo es una comparación operativa simplificada. No calcula impuestos, financiación ni el valor temporal del dinero. Para decidir entre proyectos grandes necesitarás un análisis más completo. Para detectar una propuesta que solo funciona con supuestos optimistas, suele ser suficiente como primera revisión.

## Recoge estos datos antes de hacer números

| Dato                   | Cómo conseguirlo                                 | Error que conviene evitar                 |
| ---------------------- | ------------------------------------------------ | ----------------------------------------- |
| Inversión inicial      | Presupuesto con contenido, migración y formación | Contar únicamente el diseño               |
| Coste mensual          | Alojamiento, licencias, soporte y captación      | Olvidar suscripciones anuales             |
| Contactos cualificados | Registro comercial con criterio estable          | Incluir spam y consultas fuera de alcance |
| Porcentaje de cierre   | Clientes divididos entre contactos cualificados  | Usar una semana excepcional               |
| Margen por cliente     | Ventas menos costes variables asociados          | Confundir margen con facturación          |
| Ahorro comprobado      | Gasto que realmente desaparece                   | Convertir todo minuto liberado en dinero  |

Si faltan datos, escribe un rango y su procedencia. Una estimación del responsable comercial puede ser útil, siempre que aparezca como hipótesis y se revise después. Poner dos decimales no hace más fiable una cifra desconocida.

Para una web nueva, empieza por el proceso actual: cuántas consultas llegan por recomendaciones, teléfono o redes, cuántas encajan y cuántas contratan. Ese registro ofrece un punto de partida mejor que copiar una tasa de conversión de otro sector.

## Ejemplo: una web de servicios con dos clientes adicionales al mes

Supongamos lo siguiente, solo para practicar el cálculo:

- Inversión inicial de 2.400 euros.
- Funcionamiento de 80 euros al mes, incluido todo el gasto incremental previsto en este ejemplo.
- Diez contactos cualificados adicionales al mes.
- Un 20% de esos contactos termina contratando: dos clientes adicionales.
- Cada cliente deja 250 euros de margen después de prestar el servicio.

El margen adicional mensual sería `10 × 20% × 250 = 500 euros`. Durante doce meses serían 6.000 euros. El coste del primer año sería `2.400 + 12 × 80 = 3.360 euros`.

El resultado neto atribuible sería `6.000 - 3.360 = 2.640 euros`. El ROI del primer año sería `2.640 / 3.360 × 100 = 78,6%`.

Este porcentaje describe las hipótesis del ejemplo. No demuestra que una web de ese precio vaya a producir esos contactos. Antes de aceptarlo, preguntaría de dónde salen las diez solicitudes adicionales y si el equipo tiene capacidad para atender los trabajos.

## Cuánto tarda en recuperarse la inversión

El plazo simple de recuperación usa el beneficio mensual después de funcionamiento:

```text
Beneficio mensual neto = margen adicional mensual - coste mensual
Meses para recuperar inversión = inversión inicial / beneficio mensual neto
```

En el ejemplo, `500 - 80 = 420 euros` al mes y `2.400 / 420 = 5,7 meses`. Esto supone que el resultado empieza desde el primer mes y permanece estable.

Si los primeros tres meses no producen ventas adicionales pero cuestan 80 euros mensuales, se acumulan 240 euros más antes de llegar al ritmo previsto. Quedarían por recuperar 2.640 euros: unos 6,3 meses a 420 euros netos, además de los tres meses iniciales. El plazo total se acerca a 9,3 meses.

Cuando el beneficio mensual neto es cero o negativo, esta fórmula no da un plazo de recuperación útil. Hay que cambiar el coste, el alcance o los supuestos comerciales. Esperar más tiempo no corrige una pérdida mensual constante.

## Calcula tres escenarios antes de aprobar el proyecto

Manteniendo la inversión de 2.400 euros, el coste mensual de 80 y el margen de 250 euros por cliente:

| Escenario ilustrativo | Clientes adicionales al mes | Margen mensual | ROI del primer año | Recuperación simple |
| --------------------- | --------------------------: | -------------: | -----------------: | ------------------: |
| Prudente              |                0,5 de media |          125 € |             -55,4% |          53,3 meses |
| Central               |                           2 |          500 € |              78,6% |           5,7 meses |
| Favorable             |                           3 |          750 € |             167,9% |           3,6 meses |

Medio cliente al mes significa un cliente cada dos meses como promedio. Los plazos suponen actividad estable desde el inicio; no incluyen la demora del ejemplo anterior.

Si la decisión solo sale bien en la fila favorable, reduciría el alcance inicial. Puede bastar una página de servicio clara, un formulario fiable y una forma de registrar oportunidades antes de construir un catálogo enorme. La lista de [elementos de una web profesional que capta clientes](/es/blog/que-debe-tener-web-profesional-para-captar-clientes/) ayuda a elegir esas primeras piezas.

## Cuánto puede ahorrar una pyme con su web

Depende del trabajo que deje de hacer y del coste que desaparezca realmente. Publicar horarios y requisitos puede reducir llamadas. Permitir reservas puede evitar intercambios de mensajes. Recoger datos completos puede acortar la preparación de presupuestos.

Mide primero una muestra del proceso actual. Por ejemplo: treinta solicitudes mensuales requieren ocho minutos de transcripción cada una. Son cuatro horas al mes. Después del cambio, comprueba cuántas siguen necesitando revisión y cuánto dura cada revisión.

Si esas cuatro horas pasan a una tarea útil, has recuperado capacidad. Si el salario sigue siendo el mismo, no has reducido automáticamente el gasto. Anota las horas por separado. Solo añádelas como ahorro monetario al ROI cuando puedas explicar qué gasto se evita, como horas extraordinarias o un servicio externo que dejas de contratar.

Tampoco sumes dos veces el mismo efecto. Si usas las horas recuperadas para atender los clientes adicionales del ejemplo, su valor puede estar ya reflejado en el margen de esos trabajos. La guía sobre [cuándo merece la pena automatizar procesos](/es/blog/automatizar-procesos-empresa-cuando-merece-la-pena/) desarrolla esta decisión cuando el ahorro depende de conectar herramientas.

## Cómo medir contactos que terminan en ventas

Una base sencilla es registrar fecha, canal conocido, servicio solicitado, estado comercial y resultado. Usa un identificador para relacionar el contacto con el presupuesto y evitar duplicados. La persona que atiende la consulta debe poder corregir el origen si el cliente explica que llegó por una recomendación.

En GA4, Google documenta eventos como `generate_lead`, `qualify_lead` y `close_convert_lead` para representar etapas de captación. Su [documentación de eventos recomendados](https://support.google.com/analytics/answer/9267735?hl=es) explica cuándo utilizarlos. El registro comercial sigue siendo necesario para saber qué ocurrió después del formulario.

Prueba el recorrido completo: envío aceptado, entrada en el CRM, respuesta del equipo y cambio de estado. Medir un clic como si fuera una solicitud recibida infla las cifras. La guía para [integrar CRM, formularios y pagos](/es/blog/integrar-crm-formularios-pagos/) cubre las piezas y los fallos que suelen quedar entre herramientas.

La atribución reparte crédito entre interacciones; no demuestra por sí sola que todas esas ventas sean nuevas. Google explica esa distinción operativa en su [introducción a la atribución](https://support.google.com/analytics/answer/10596866?hl=es). Una persona puede conocerte por una recomendación, buscarte después y enviar un formulario. Conviene conservar esa incertidumbre en el informe.

## Qué revisar después de publicar

Durante las primeras semanas, comprueba que el formulario llega y que el equipo responde. Después compara periodos completos teniendo en cuenta temporada, campañas y duración habitual de la venta. Un negocio con contratos que tardan dos meses en cerrarse no puede evaluar margen al terminar la primera semana.

Separaría el seguimiento en dos preguntas: si llegan oportunidades adecuadas y si esas oportunidades dejan margen. Más impresiones con consultas irrelevantes pueden aumentar el trabajo sin mejorar el resultado.

Revisa también los costes reales. Una licencia nueva, más horas de soporte o contenido pendiente cambian el cálculo. Si las visitas llegan pero nadie consulta, inspecciona oferta, navegación y contacto antes de comprar más tráfico. Si llegan consultas buenas pero no se cierran, habla con quien prepara los presupuestos.

## Preguntas frecuentes

### ¿Cuántas visitas necesita una web para ser rentable?

No hay una cifra universal. Necesitas relacionar visitas pertinentes, contactos cualificados, cierres y margen. Una empresa que vende trabajos especializados puede necesitar pocos clientes; otra con margen pequeño necesitará más operaciones.

### ¿Puedo contar clientes recurrentes?

Sí, con un periodo definido y una estimación de retención defendible. En un cálculo anual cuenta el margen esperado dentro de ese año. Evita introducir años de ingresos futuros en el numerador mientras solo incluyes doce meses de costes.

### ¿Una web que no vende directamente puede aportar valor?

Puede apoyar recomendaciones, selección de proveedores o atención al cliente. Registra esos usos con evidencias: consultas que llegan preparadas, documentación utilizada o tareas evitadas. Si no puedes atribuirles dinero con confianza, descríbelos como beneficios operativos separados.

### ¿Qué debería pedir en el presupuesto?

Un alcance concreto, costes recurrentes, responsabilidades de medición y criterios para aceptar formularios e integraciones. Para preparar una [web de negocio](/es/services/diseno-web-wordpress/), trae tus consultas actuales, margen aproximado y tareas repetidas. Con esa información se puede elegir un alcance que puedas evaluar después.
